 <h1>Adaptive Robot Gripper for Improved Object Manipulation</h1>
      <p class="subtitle">
        A Fusion 360 design project tackling grasp diversity and reliable handling across varied object shapes and sizes.
      </p>

  <section class="card">
      <h2>Overview</h2>
      <p>
        The goal of this project is to design and prototype an <strong>adaptive robot gripper</strong> in Fusion 360 that
        overcomes limitations of traditional grippers in grasp variety and stability. Many current grippers struggle with
        objects of diverse geometries, reducing automation efficiency. This project explores a mechanism and assembly that
        adapts to object shape while maintaining a firm, controlled hold.
      </p>
    </section>

   <h2>Introduction</h2>
        <ul class="checklist">
          <li>Robot grippers are end-effectors that grasp, hold, and manipulate items.</li>
          <li>They enable robots to perform repeatable handling tasks across industries.</li>
          <li>Integrated sensors/feedback help ensure firm grip without damaging objects.</li>
          <li>Grippers can mount on robotic hands, arms, or other end-effectors for precise control.</li>
        </ul>

  <h2>Applications & Use Cases</h2>
        <ol class="numbered">
          <li>
            <strong>Manufacturing & Assembly:</strong>
            <p>Pick-and-place of parts across stations, kitting, and component feeding.</p>
          </li>
          <li>
            <strong>Logistics & Warehousing:</strong>
            <p>Order fulfillment, bin picking, cartonization, and object sorting.</p>
          </li>
          <li>
            <strong>Material Handling:</strong>
            <p>Loading/unloading onto conveyors, pallets, or vehicles in automated lines.</p>
